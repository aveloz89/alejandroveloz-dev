My development methodology

How I work with AI agents.

I created a methodology for Claude Code that coordinates specialized agents, preserves project context and automates checks. I define the goals and make the product and architecture decisions.

Applied in Marvin, Easy Quotes and 3Dimensional.

Claude CodeQACI/CD
  1. 01

    Define and design

    Goals, acceptance criteria and technical contracts come before implementation. Architecture and design agents help break down the work.

  2. 02

    Implement with context

    Frontend and backend agents work on scoped tasks with tests. Persistent planning and handoffs carry project context across sessions.

  3. 03

    Review and verify

    QA and security reviews, tests before commits and checks before pushes and merges. The methodology includes tests for its own controls.

Agents support implementation and review. I remain responsible for technical decisions and what gets delivered.
